## 线路和机房：洛杉矶 DC-02 到底是不是 CN2

不是。洛杉矶 DC-02 的回程实测数据是：广州电信走 163、广州联通走 4837、广州移动走 CMI，三网都标注普通线路，没有 CN2 的标记。延迟大致在电信 269ms、联通 236ms、移动 163ms 这个区间，属于美西普通线路的正常水平。

机房的实际情况是，RackNerd 的节点分属不同上游。洛杉矶 DC-02 属于 MC 机房，对大陆方向相对最友好，也是被抢得最快的节点，很多低价活动套餐干脆不开放 DC-02 选项。其余洛杉矶节点和圣何塞、西雅图、达拉斯、芝加哥、纽约、新泽西、阿什本等地多为 CC 机房。关于节点总数，官方和第三方说法从 9 个到 20 个地点不等，不必纠结具体数字，能选的就那些。

选机房的规则可以简化成三条：

- 访客主要在国内：优先洛杉矶 DC-02，其次圣何塞。接受晚高峰波动这个前提。

几条具体的政策和费用：

- **换 IP**：新买的机器如果开到被墙的 IP，72 小时内可以免费换一次，官方知识库确认了这个政策。超过 72 小时或者老机器 IP 被墙，后台自助付费换，一次 3 美元。
- **PUSH push 服务**：把机器转到别的账户，一次 8 美元，需要开工单申请。
- **独立服务器开通**：VPS 是自动开通，独服人工配置，官方说明要 24 到 72 小时。
- **退款**：官方知识库写得很清楚，按服务条款不提供退款，也没有退款保证。立即取消只是触发 24 小时终止倒计时，已付的钱不退回。账户里的预付款余额同样不退。用争议付款（chargeback）处理已经被判定违规的服务，还可能被收 125 到 250 美元的行政费。

## “灵车”这个称号是怎么来的

2019 年 RackNerd 刚成立时，国外社区有人发帖，称它是 alpharacks、nfphosting、hostmybytes、woothosting 这几家跑路商家的老板新开的品牌，并列举了一些佐证。这几个名字在当时的便宜 VPS 圈子里是“跑路”的代名词，RackNerd 因此被叫成“灵车”，很多人预测它撑不了多久。

几年过去，这个判断没有兑现。有用户 2020 年黑五买的机器一直续费到现在，稳定在线；2023 年又加购了洛杉矶 DC-02。它没有变成一家以稳定著称的商家，但在低价段活了下来，也积累了一批连续续费几年的老客户。

需要保持的判断是：便宜商家的系统性风险始终存在，重要数据自己留一份异地备份，这个习惯和选哪家无关。

## 什么人不该买 RackNerd

- 面向大陆用户的高流量生产站。普通线路晚高峰的波动和丢包没法靠配置解决，这类业务该选线路更好的商家，价格贵不少，但稳定性是另一回事。
- 需要 CPU 独占性能的计算任务。全系 VPS 都是共享 CPU，跑编译、渲染、模型推理会很难受。
- 需要托管运维或一键部署生态的团队。RackNerd 卖的是非托管机器，面板能装系统、开 VNC、装一些一键应用，但没有人替你运维。
- 对即时响应有硬要求、或者需要退款兜底的场景。没有在线客服，也没有退款。
- 把备份和高级 DDoS 防护当刚需的人。官方宣传套餐含 DDoS 防护，但低价套餐的实际防护能力和是否附带自动备份，下单前要自己确认清楚，别默认全都有。
